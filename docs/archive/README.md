# 개발 이력 보관

이 폴더는 과거 시점의 설명서를 보관한다. 인수인계 문서의 상대 링크 4개만 현재 위치로 수정했고, 나머지 본문은 보존했다. 현재 운영 절차로 그대로 실행하지 않는다.

|기존 경로|보관 위치|
|---|---|
|docs/legacy/README_*.md|legacy/README_*.md|
|v11-preview의 인수인계·멀티 메모·v13 integration·README·v12 checklist/setup 문서|v11-preview/의 같은 파일명|

원문에 기록된 코드 경로는 당시 저장소 기준이다. 현재 앱·data·photos·sync-worker는 저장소 루트에 있다. migration SQL은 ../../sync-worker/migration-v12.1.sql에 보존한다. 사진 감사와 최종 사용성 보고서는 ../../v11-preview/에 그대로 있다. V13_ROOT_PROMOTION.md의 docs/legacy 표기는 승격 당시 기록이며 현재 위치는 이 폴더의 legacy/다.

삭제한 개발 브랜치의 원래 SHA와 복구 패치는 [cleanup 보고서](../V13_CLEANUP.md)와 git/에서 확인한다. 운영 배포 기록은 [운영 결과](../releases/V13_PRODUCTION_DEPLOYMENT_RESULT.md)에 보관한다.
