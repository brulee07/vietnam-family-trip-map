# v12.7 메모 사진 첨부 테스트

## 핵심 기능
- [ ] 일정 → 메모 추가/편집을 열면 오른쪽 위에 사진 추가 아이콘이 보인다.
- [ ] 사진 아이콘을 누르면 휴대폰 사진 선택창이 열린다.
- [ ] 사진을 선택하면 앱용 JPEG로 자동 압축되고 미리보기가 나타난다.
- [ ] 텍스트만 저장할 수 있다.
- [ ] 사진만 저장할 수 있다.
- [ ] 텍스트 + 사진을 함께 저장할 수 있다.
- [ ] 저장된 사진 메모가 일정 경로의 지정 위치에 표시된다.
- [ ] 편집 모드에서 사진이 있는 메모도 ⠿ 손잡이로 드래그 이동할 수 있다.
- [ ] 메모 사진 썸네일을 누르면 크게 볼 수 있다.
- [ ] 메모 편집에서 사진만 삭제할 수 있다.
- [ ] 메모 삭제를 누르면 텍스트와 사진이 함께 삭제된다.

## 기존 기능 회귀 확인
- [ ] 장소 카드 드래그 순서 변경이 정상 동작한다.
- [ ] Today Mode에서 사진 메모가 표시된다.
- [ ] 지도 방문 순서에 사진 메모가 `사진` 표시와 함께 나타난다.
- [ ] 장소 사진 68장 표시가 기존처럼 정상이다.
- [ ] 가족 일정 텍스트 동기화가 기존처럼 정상이다.

## v12.7 범위
메모 사진은 현재 **선택한 기기에만 저장**된다. 가족 9대 간 사진 동기화는 아직 포함하지 않는다.
