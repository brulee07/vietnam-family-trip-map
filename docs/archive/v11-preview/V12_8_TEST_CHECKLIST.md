# v12.8 Supabase 가족 메모 사진 동기화 테스트

1. `/health`가 `version: 12.8-supabase`, `photoSync: true`인지 확인
2. A폰과 B폰이 같은 가족 공유방에 연결되어 있는지 확인
3. A폰에서 텍스트+사진 메모 저장 → `지금 동기화`
4. B폰에서 `지금 동기화` → 같은 메모 썸네일과 확대보기가 표시되는지 확인
5. B폰에서 사진 교체 → A폰 동기화 후 교체 사진 확인
6. A폰에서 사진만 삭제 → B폰 동기화 후 사진이 사라지고 텍스트 메모는 유지되는지 확인
7. 비행기 모드에서 사진 메모 추가 → 온라인 복귀 → `지금 동기화` → 다른 폰에 사진 표시 확인
8. 기존 v12.7 로컬 전용 사진이 있는 폰에서 첫 동기화 후 다른 폰에 표시되는지 확인

주의: 공개 버킷이므로 사진 URL을 아는 사람은 사진을 열 수 있습니다. 업로드/삭제는 Worker의 Secret key를 통해서만 수행합니다.
