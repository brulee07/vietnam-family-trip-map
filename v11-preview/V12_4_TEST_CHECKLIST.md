# v12.4 경로 메모 테스트

1. 일정 > 1/11 다낭을 엽니다.
2. `메모 추가/편집`에서 `이동: 렌트차량`을 입력합니다.
3. 표시 위치를 `1번과 2번 사이 · 다낭 국제공항 → 뉴 오리엔트 호텔`로 선택해 저장합니다.
4. 메모가 두 장소 사이의 타임라인에 표시되는지 확인합니다.
5. `편집`을 눌러 메모의 `↑ 위로`, `↓ 아래로`, `메모 삭제`가 보이는지 확인합니다.
6. Today Mode에서 같은 메모가 같은 순서에 표시되는지 확인합니다.
7. 지도 > 일정 장소만의 방문 순서에도 메모가 같은 위치에 표시되는지 확인합니다. 메모 자체에는 지도 핀이 생성되지 않습니다.
8. 가족 공유를 사용하는 경우 다른 휴대폰에서 메모 내용과 위치가 함께 동기화되는지 확인합니다.

기존 메모는 기본적으로 예전처럼 일정 아래에 표시됩니다. 메모 편집에서 위치를 선택한 경우에만 경로 사이로 이동합니다.
