# 가족여행 지도 v11.7.1 — 맞춤 조정 AI 연결 안정화

## v11.7.1 preview

- v11.7의 **가족·날씨 맞춤 일정 조정** 기능을 유지합니다.
- 맞춤 조정 요청은 현재 일정에 필요한 장소·가족·날씨 정보만 보내도록 컨텍스트를 축소해 Worker/AI 응답 지연 가능성을 낮췄습니다.
- AI 호출이 네트워크 오류, 시간 초과, HTTP 429 또는 5xx로 실패하면 앱이 **자동으로 한 번 재시도**합니다.
- 맞춤 조정은 1회 요청당 최대 35초, 일반 AI 질문은 최대 30초를 기다립니다.
- 자동 재시도까지 실패하면 HTTP 상태 또는 시간 초과 여부를 화면에 구분해 표시합니다.
- Worker 주소는 기존 `https://vietnam-family-trip-ai.brulee07.workers.dev/chat`을 그대로 사용합니다. Worker 재배포는 필요하지 않습니다.
- 기존 APP_ORDER 추천 순서 검증, 추천 순서 적용, 이전 순서 복원 기능은 그대로 유지합니다.
- 화면/AI 설정/Service Worker 캐시를 v11.7.1 preview로 갱신했습니다.

## 테스트 권장

1. 장소가 많은 날짜에서 `AI 여행 비서`를 엽니다.
2. `맞춤 조정`을 누릅니다.
3. 날씨가 자동으로 반영되고 AI 답변이 오는지 확인합니다.
4. 답변 아래 `AI 가족·날씨 맞춤 일정` 카드가 표시되는지 확인합니다.
5. 일시적인 연결 지연이 발생하면 앱이 자동으로 한 번 재시도하는지 확인합니다.
