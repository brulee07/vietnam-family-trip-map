# 가족여행 지도 v12.0 — 가족 공유·동기화 기반

## v12.0 preview

- v11.9.2 Today Mode와 AI 기능을 그대로 유지합니다.
- **가족 공유·동기화** 기능을 추가했습니다.
- 한 기기에서 가족 공유방을 만들고, 초대 링크로 다른 휴대폰이 참여할 수 있습니다.
- 공유 대상: 일정 순서, 하루 메모, 저장 장소, 직접 추가 장소, Today Mode 진행 상태, 체크리스트.
- AI 대화, AI 적용 전 복원 기록, 백업 기록, 기기별 설정은 공유하지 않습니다.
- 가족이 동시에 수정하면 항목별 수정 시각을 기준으로 병합하고, 서버 revision 충돌도 한 번 자동으로 재병합합니다.
- 앱이 열려 있는 동안 약 15초 간격으로 최신 내용을 확인하고, 로컬 편집 후에는 자동으로 업로드합니다.
- 초대 링크의 공유키는 URL fragment(`#`)에 넣어 GitHub Pages 서버로 전송되지 않도록 했습니다.
- 동기화 서버는 기존 AI Worker와 분리된 **Cloudflare Worker + D1** 구조입니다.

## 가족 동기화 배포 순서

1. `sync-worker/` 폴더의 안내에 따라 D1 데이터베이스와 별도 Sync Worker를 배포합니다.
2. 배포된 Worker 기본 주소를 `sync-config.js`의 `endpoint`에 입력합니다.
3. GitHub Pages에 다시 배포한 뒤 `도구 → 가족 일정 동기화 → 가족 공유 시작`을 누릅니다.
4. 생성된 초대 링크를 가족 휴대폰에 전달합니다.
5. 가족 휴대폰에서 링크를 열고 `가족 일정으로 맞추기` 또는 `병합`을 선택합니다.

> v12.0 ZIP에는 Sync Worker 소스와 D1 schema가 포함되어 있지만, Cloudflare에 실제 Worker/D1을 배포하기 전에는 가족 동기화가 실행되지 않습니다.

## v11.9.2 preview

- v11.8 안정화 기능과 AI 동선 최적화·가족/날씨 맞춤 조정·적용/복원 기능을 그대로 유지합니다.
- 하단 메뉴에 **오늘(Today Mode)** 을 추가했습니다.
- 여행 기간(2027-01-11~25)에는 베트남 현지 날짜를 인식해 앱 시작 시 해당 날짜의 Today Mode를 자동으로 엽니다.
- 여행 전에는 선택한 날짜를 **미리보기**로 사용할 수 있습니다.
- Today Mode에서 가족 수, 일정 진행도, 현재 날씨, 이동일 정보를 한 화면에 확인할 수 있습니다.
- **시작 장소/다음 장소 → 지금 출발 → 도착·완료** 흐름으로 일정 진행 상태를 기록합니다.
- 장소별 완료 표시는 날짜별로 기기에 저장되며 일정 순서가 바뀌어도 장소 기준으로 유지됩니다.
- Google Maps의 현재 위치 기반 길찾기로 **지금 출발**을 연결합니다.
- 날짜별 **가족 준비 체크리스트**를 제공하며 항목 추가·완료·삭제가 가능합니다.
- Today Mode의 **오늘 메모**는 기존 일정 메모와 같은 데이터를 사용하므로 일정 화면과 서로 동기화됩니다.
- Today Mode 진행 상태와 체크리스트도 v11 백업/복원 데이터에 포함됩니다.
- 홈 화면에 Today Mode 바로가기를 추가했습니다.

## 테스트 권장

1. 홈 또는 하단 메뉴에서 `오늘`을 열어 1/11 미리보기가 표시되는지 확인합니다.
2. 날짜 선택에서 1/14 꾸이년처럼 장소가 많은 날을 선택합니다.
3. `시작 완료` 또는 `도착·완료`를 눌렀을 때 다음 장소가 자동으로 바뀌는지 확인합니다.
4. `지금 출발`이 Google Maps 길찾기로 연결되는지 확인합니다.
5. 체크리스트 항목을 체크하고 새 항목을 추가한 뒤 화면을 다시 열어 상태가 유지되는지 확인합니다.
6. 오늘 메모를 추가한 뒤 일정 화면에서도 같은 메모가 보이는지 확인합니다.
7. 백업 후 복원했을 때 Today Mode 진행 상태와 체크리스트가 유지되는지 확인합니다.



### v11.9.2 Today Mode 개선
- `지금 출발 → 도착 완료 → 다음 장소` 흐름으로 단순화
- 오늘 일정 진행 막대 추가
- 장소 안내는 3줄 미리보기 + 더보기/접기
- 완료 장소 시각 처리 강화
- 체크리스트 완료 항목을 아래쪽으로 자동 정렬
- 메모가 없을 때 `+ 메모 작성`만 표시해 공간 절약
- Today Mode에서 지도를 열면 완료 장소와 다음 장소를 강조


### v11.9.2 길찾기 동작 개선
- 여행 전 **미리보기**에서는 `지금 출발` 대신 `지도에서 보기`를 표시합니다.
- 미리보기의 `경로 미리보기`는 현재 위치가 아니라 호텔(또는 직전 일정 장소)에서 다음 장소까지 Google Maps 경로를 엽니다.
- 실제 여행일에는 기존처럼 `지금 출발`이 현재 위치 기반 길찾기를 열고, 이후 `도착 완료`로 진행 상태를 기록합니다.
- 이동 중 표시는 12시간이 지나면 자동 만료되어 오래된 테스트 상태가 실제 여행에 남지 않습니다.
