# 가족여행 지도 v12.4 — 경로 사이 메모 배치

## v12.4 preview
- 기존 하루 메모를 일정 아래뿐 아니라 첫 장소 앞, 장소와 장소 사이, 마지막 장소 뒤에 배치할 수 있습니다.
- 일정 편집 모드에서 경로 메모를 위/아래로 이동하거나 삭제할 수 있습니다.
- Today Mode에도 같은 위치에 경로 메모가 표시됩니다.
- 메모 위치는 가족 동기화와 백업/복원에 포함됩니다.
- v12.3의 로컬 사진 52장 및 기존 기능을 유지합니다.


- 가족 공유에 연결된 **각 스마트폰의 이름을 앱에서 바로 변경**할 수 있습니다.
- 기기 이름은 최대 **20자**이며, `아빠`, `엄마`, `할머니`, `민준 iPhone`처럼 9대를 쉽게 구분하는 이름을 권장합니다.
- 같은 이름이 이미 있으면 입력 단계와 참여 기기 목록에서 **중복 이름 경고**를 표시합니다. 중복 이름 사용을 막지는 않지만 저장 전에 한 번 더 확인합니다.
- 참여 기기 목록의 **이 기기 → 이름 변경** 버튼으로 바로 수정할 수 있고, 가족 공유 카드의 `이 기기` 영역에서도 이름 변경이 가능합니다.
- 이름 저장 후 즉시 가족 Sync Worker에 반영하고 참여 기기 목록을 새로고침합니다.
- **Cloudflare D1/Sync Worker는 v12.1 그대로 사용**합니다. v12.2는 앱 UI·기기 이름 관리 개선이므로 서버 재배포나 D1 마이그레이션이 필요하지 않습니다.

- 한 가족 공유방에 **최대 9대의 스마트폰**이 참여할 수 있도록 서버에서 제한과 상태 추적을 추가했습니다.

- 기기 이름을 변경하면 다음 동기화 때 서버 목록에 반영됩니다.
- 수동 `지금 동기화`와 15초 자동 확인을 유지하고, 도구 화면에서는 참여 기기 목록도 갱신됩니다.
- 9대가 동시에 수정할 때 revision 충돌이 연속으로 발생해도 **최대 4회 재병합·재시도 + 짧은 랜덤 지연**으로 안정성을 높였습니다.
- 이 기기 연결 해제 시 서버의 참여 기기 슬롯도 함께 반환합니다. 오래된 오프라인 기기는 목록에서 제거할 수 있습니다.
- 기존 v12.0 공유방을 그대로 사용할 수 있으며, D1에 `devices` 테이블과 9대 제한 trigger만 추가하면 됩니다.

## v12.0 preview

- v11.9.2 Today Mode와 AI 기능을 그대로 유지합니다.
- **가족 공유·동기화** 기능을 추가했습니다.
- 한 기기에서 가족 공유방을 만들고, 초대 링크로 다른 휴대폰이 참여할 수 있습니다.
- 공유 대상: 일정 순서, 하루 메모, 저장 장소, 직접 추가 장소, Today Mode 진행 상태, 체크리스트.
- AI 대화, AI 적용 전 복원 기록, 백업 기록, 기기별 설정은 공유하지 않습니다.
- 가족이 동시에 수정하면 항목별 수정 시각을 기준으로 병합하고, 서버 revision 충돌도 한 번 자동으로 재병합합니다.
- 앱이 열려 있는 동안 약 15초 간격으로 최신 내용을 확인하고, 로컬 편집 후에는 자동으로 업로드합니다.
- 초대 링크의 공유키는 URL fragment(`#`)에 넣어 GitHub Pages 서버로 전송되지 않도록 했습니다.
- 동기화 서버는 기존 AI Worker와 분리된 **Cloudflare Worker + D1** 구조입니다.

## 가족 동기화 배포 순서

1. `sync-worker/` 폴더의 안내에 따라 D1 데이터베이스와 별도 Sync Worker를 배포합니다.
2. 배포된 Worker 기본 주소를 `sync-config.js`의 `endpoint`에 입력합니다.
3. GitHub Pages에 다시 배포한 뒤 `도구 → 가족 일정 동기화 → 가족 공유 시작`을 누릅니다.
4. 생성된 초대 링크를 가족 휴대폰에 전달합니다.
5. 가족 휴대폰에서 링크를 열고 `가족 일정으로 맞추기` 또는 `병합`을 선택합니다.

> v12.0부터 Sync Worker 소스와 D1 schema가 ZIP에 포함됩니다.

### v11.9.2 Today Mode 개선
- `지금 출발 → 도착 완료 → 다음 장소` 흐름으로 단순화
- 오늘 일정 진행 막대 추가
- 장소 안내는 3줄 미리보기 + 더보기/접기
- 완료 장소 시각 처리 강화
- 체크리스트 완료 항목을 아래쪽으로 자동 정렬
- 메모가 없을 때 `+ 메모 작성`만 표시해 공간 절약
- Today Mode에서 지도를 열면 완료 장소와 다음 장소를 강조


### v11.9.2 길찾기 동작 개선
- 여행 전 **미리보기**에서는 `지금 출발` 대신 `지도에서 보기`를 표시합니다.
- 미리보기의 `경로 미리보기`는 현재 위치가 아니라 호텔(또는 직전 일정 장소)에서 다음 장소까지 Google Maps 경로를 엽니다.
- 실제 여행일에는 기존처럼 `지금 출발`이 현재 위치 기반 길찾기를 열고, 이후 `도착 완료`로 진행 상태를 기록합니다.
- 이동 중 표시는 12시간이 지나면 자동 만료되어 오래된 테스트 상태가 실제 여행에 남지 않습니다.
