# 가족여행 지도 v11.8 — 안정화·복구 강화

## v11.8 preview

- v11.7.2의 AI 동선 최적화, 가족·날씨 맞춤 조정, 추천 순서 적용, 이전 순서 복원 기능을 그대로 유지합니다.
- AI 오류를 HTTP 400/401/403/429/5xx, 시간 초과, 오프라인·네트워크 오류로 구분해 안내합니다.
- AI 호출이 실패하면 답변 아래 **다시 시도** 버튼이 표시되며, 같은 질문과 같은 분석 모드로 재실행합니다.
- `AI 연결 설정`에 **연결 테스트** 버튼을 추가했습니다.
- 백업 파일에 앱 버전·생성 시각 메타데이터를 추가하고, 복원 전에 편집 일정·메모·저장 장소·추가 장소 개수를 미리 보여줍니다.
- 백업 복원 직전의 현재 데이터를 자동 임시 보관하고, 여행 도구에서 **복원 전 상태 되돌리기**를 한 번 실행할 수 있습니다.
- 백업 복원 시 일정 키·장소 참조·추가 장소·AI 복원 기록까지 검증해 손상된 파일이 현재 데이터를 덮어쓰지 않도록 강화했습니다.
- 여행 도구에 앱 상태와 **새 버전 확인** 버튼을 추가했습니다.
- Service Worker 등록에 버전 쿼리와 `updateViaCache: none`을 적용해 이전 JS가 남는 가능성을 낮췄습니다.
- 오프라인/온라인 전환 시 상태를 안내하며, 오프라인에서도 캐시된 일정과 저장 데이터는 계속 볼 수 있습니다.

## 테스트 권장

1. `도구 → 내 일정 백업·복원 → 백업 내려받기`를 실행합니다.
2. 같은 백업을 `백업 복원`에서 선택해 복원 전 미리보기 화면이 나타나는지 확인합니다.
3. 복원 후 `복원 전 상태 되돌리기` 버튼이 나타나는지 확인합니다.
4. `AI 여행 비서 → AI 연결 설정 → 연결 테스트`가 정상인지 확인합니다.
5. AI 연결이 일시 실패할 경우 오류 답변 아래 `다시 시도` 버튼이 나타나는지 확인합니다.
