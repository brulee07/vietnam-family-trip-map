# 가족여행 지도 v11.7 — AI 날씨·가족 맞춤 일정 조정

## v11.7 preview

- AI 여행 비서의 빠른 질문에 **맞춤 조정**을 추가했습니다.
- 맞춤 조정 실행 시 선택한 도시의 현재 날씨를 자동으로 확인하고, 가족 구성·장소 특성·체류시간·기존 일정과 함께 AI에 전달합니다.
- 나트랑 구간은 저장된 가족 정보(성인 4명 + 아이 5명, 아이 나이 15·12·10·8·7세)를 활용합니다. 다른 도시에서는 데이터에 없는 세부 연령이나 건강 상태를 추정하지 않도록 지시합니다.
- 현재 날씨의 날짜가 선택한 여행 날짜와 다르면 **여행일 예보로 간주하지 않고 참고값으로만 사용**하도록 AI 프롬프트와 화면 안내에 명시했습니다. 여행 당일에는 동일 기능이 현장 날씨 판단에 직접 활용됩니다.
- AI는 현재 일정의 장소를 추가·삭제하지 않고 순서만 조정하며, 기존 v11.5의 APP_ORDER 검증과 보조 복구 파서를 그대로 사용합니다.
- 결과는 **현재 순서 / 추천 순서** 비교 카드로 표시하고, 사용자가 **추천 순서 적용**을 눌렀을 때만 실제 일정에 반영됩니다.
- v11.6의 **이전 순서로 복원** 기능도 그대로 유지됩니다.
- 맞춤 조정 전 날씨가 없거나 30분 이상 지난 경우 새로 확인합니다. 날씨 연결에 실패하면 가족 구성과 장소 특성 중심으로 계속 분석합니다.
- 화면/AI 설정/Service Worker 캐시를 v11.7 preview로 갱신했습니다.

## 테스트 권장

1. 여러 장소가 있는 날짜에서 `AI 여행 비서`를 엽니다.
2. `맞춤 조정`을 누릅니다.
3. 날씨가 자동으로 카드에 반영되는지 확인합니다.
4. AI 답변 아래 `AI 가족·날씨 맞춤 일정` 카드의 현재/추천 순서를 비교합니다.
5. `추천 순서 적용` 후 일정 화면에서 변경을 확인하고, 필요하면 `이전 순서로 복원`을 시험합니다.

> Open-Meteo의 현재 날씨는 미래 여행일 예보가 아닙니다. 선택 날짜와 관측 날짜가 다르면 앱과 AI 모두 참고값으로만 취급합니다.
