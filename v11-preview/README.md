# 가족여행 지도 v11.5.1 — AI 추천 동선 파싱 핫픽스

## v11.5.1 preview 수정

- AI가 숨은 `ROUTE_ORDER` 형식을 누락하더라도 자연어 답변의 `추천 순서:`와 화살표 동선을 읽어 현재 일정 장소와 자동 매칭합니다.
- 자연어 추출도 현재 일정의 모든 장소가 정확히 한 번씩 포함된 경우에만 추천 카드와 적용 버튼을 생성합니다.
- 기존 `ROUTE_ORDER` 형식은 우선 사용하며, 실패할 때 자연어 파서를 사용하는 이중 방식으로 보강했습니다.

- AI의 **동선 최적화** 결과를 현재 일정과 비교해 보여주는 `AI 추천 동선` 카드를 추가했습니다.
- AI 추천이 현재 일정의 장소를 정확히 한 번씩 포함하는 순열일 때만 `추천 순서 적용` 버튼을 활성화합니다.
- 추천 과정에서 장소가 추가·삭제·중복되거나 장소 ID가 맞지 않으면 자동 적용하지 않습니다.
- 적용 전에 `현재 순서`와 `추천 순서`를 모두 표시하며, 사용자가 버튼을 눌렀을 때만 해당 날짜의 편집 일정에 저장합니다.
- AI 추천 이후 사용자가 일정을 수정했다면 기존 추천을 적용하지 않고 다시 분석하도록 안내합니다.
- 적용 후 `일정에서 확인` 버튼으로 실제 일정 화면에서 결과를 확인할 수 있습니다.
- AI와의 대화 이력에는 화면용 텍스트만 전달하고, 앱 내부의 추천 메타데이터는 Worker로 다시 보내지 않도록 정리했습니다.
- 기존 Cloudflare Worker 주소는 그대로 사용하며 별도 Worker 재배포는 필요하지 않습니다.
- 화면/AI 설정을 v11.5.1 preview로 통일하고 Service Worker 캐시를 갱신했습니다.


## v11.4.2 preview 수정

- 모바일에서 대화가 없는 초기 화면에서는 AI 입력창이 빠른 질문 버튼을 덮지 않도록 일반 흐름으로 배치했습니다.
- 대화가 시작된 뒤에는 입력창이 하단에 sticky로 유지되어 연속 질문이 편하도록 했습니다.
- 날씨 요약 칩은 상태와 기온이 말줄임표로 잘리지 않고 두 줄까지 표시되도록 조정했습니다.

- AI 여행 비서에 현재 날짜·도시·가족 규모·일정 장소·현재 날씨를 보여주는 컨텍스트 카드를 추가했습니다.
- 일정 강도, 동선 최적화, 식사·휴식, 날씨 대안, 준비물을 한 번에 질문하는 빠른 질문 버튼을 추가했습니다.
- AI 화면에서 현재 날씨를 바로 불러와 AI 컨텍스트에 포함할 수 있습니다.
- AI 답변 복사와 대화 지우기 기능을 추가했습니다.
- 현재 질문이 `message`와 `history`에 중복 전달되던 구조를 수정했습니다.
- AI에 여행 Day 번호, 편집 메모, 이동일 정보, 저장 장소를 추가로 전달합니다.
- 화면/AI 설정을 v11.4.2 preview로 통일하고 Service Worker 캐시를 갱신했습니다.

### 모바일 AI 화면 핫픽스
- AI 컨텍스트 카드를 모바일에서 3개 요약칩 형태로 압축했습니다.
- 가족 표시는 기본 구간 `가족 7명`, 나트랑 구간 `가족 9명`으로 간단히 표시합니다.
- 빠른 질문 5개가 가로 스크롤 대신 줄바꿈되어 바로 보이도록 했습니다.
- 전송 버튼 폭과 줄바꿈을 고정해 `전/송`으로 깨지지 않도록 수정했습니다.
- 입력창 하단 고정 시 콘텐츠를 가리지 않도록 모바일 여백을 조정했습니다.
- 오늘 동선은 최대 2줄 요약으로 유지합니다.

## 기존 데이터 보존

- v10.1.1 weather hotfix ZIP에서 JSON 5개를 변경 없이 복사했습니다.
- 장소 105개와 일정안 19개를 유지합니다. 도시와 장소 ID를 묶어 서로 다른 도시의 hotel 등 같은 ID가 충돌하지 않게 했습니다.
- 원본 ZIP과 원래 배포 사이트는 변경하지 않았습니다.
- 기존 브라우저에만 추가한 장소/동선은 자동 이전하지 않습니다. 기존 사이트의 저장 데이터를 별도 확보해야 합니다.
- 원본 일정안에는 선택 후보와 중복 방문이 포함되어 있습니다. 실제 방문 확정과 구분해야 합니다. 이동일에는 도시별 구간을 각각 볼 수 있습니다.

## 작동하는 흐름

일정 → 장소 선택 → 하단 간편 보기 → 상세 정보. 날짜/도시 변경, 일정 편집(위/아래 이동, 제외), 장소 추가, 메모, 도시별 장소 검색, 즐겨찾기, 지도, 백업/복원, AI 연결, 현재 날씨.

AI는 도구 메뉴의 전용 화면에 있어 저장 버튼을 가리지 않습니다. 새 장소 추가의 제목·검색어·저장 도시는 동일한 도시 상태에서 가져옵니다.

## 시험 방법

기존 사이트를 덮어쓰지 말고 GitHub 저장소에 `v11-preview` 폴더를 만들어 이 폴더 내용물을 업로드하세요. 사이트 주소 뒤에 `/v11-preview/`를 붙이면 시험할 수 있습니다. 기존 Worker는 교체하지 않아도 됩니다. 이 파일들의 직접 더블클릭 실행은 지원하지 않습니다.

편집 정보는 기기별 브라우저에 저장되며 자동 공동 편집이 아닙니다. 도구 → 백업/복원에서 파일로 옮길 수 있습니다. 새로운 하위 경로에서도 같은 출처라면 기존 AI 주소 설정을 사용할 수 있습니다.

지도 배경, 외부 장소 검색, 날씨, AI에는 인터넷이 필요합니다. 지도 연결선은 실제 도로 경로가 아닌 방문 순서입니다. 처음 온라인으로 열면 일정·장소 JSON을 캐시해 오프라인 열람에 사용합니다. 외부 지도 라이브러리와 지도 타일의 오프라인 사용은 보장하지 않습니다.

## 후속 작업 / 검증 한계

- 완료한 검사: JavaScript 구문 검사, 원본 JSON 5개 바이트 일치, 도시·날짜 18개 구간의 일정 장소 참조 검사, 도시+장소 ID 105개 중복 없음.
- 로컬 자동 브라우저 렌더링은 실행 환경의 로컬 URL 접근 제한 때문에 완료하지 못했습니다. JavaScript/JSON/압축 구조는 검사했으며, 저장 버튼의 실제 겹침 여부와 키보드가 열린 화면은 Galaxy/iPhone 실기기 확인이 필요합니다.
- 온라인 장소 검색·AI·날씨의 실서버 응답은 이번 제작에서 검증하지 않았습니다.

- 실제 가족 휴대폰에서 글자 크기와 동선을 확인한 뒤 화면을 확정합니다.
- 사진은 사용자가 제공할 실제 사진으로 후속 반영합니다. 샘플 앱의 호텔 사진은 복사하지 않았습니다.
- 기존 기기별 추가 데이터 이전, 가족 공동 저장, 이동일 도시 구간 통합 표시는 후속 범위입니다.
- 원본 영업/가격/연락처 기록은 이번에 새로 검증하지 않았습니다. 날씨는 현재 날씨이며 미래 여행일 예보를 뜻하지 않습니다.
- AI 동선 추천은 자동으로 일정을 바꾸지 않습니다. 검증된 추천에 한해 사용자가 `추천 순서 적용`을 눌러야 반영됩니다.
