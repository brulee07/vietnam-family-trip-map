1. Sync Worker에 R2 binding `PHOTOS`를 연결하고 새 worker.js Deploy
2. `/health`에서 `version: 12.8`, `photoSync: true` 확인
3. 휴대폰 A에서 가족 공유방 연결 상태 확인
4. 메모 → 사진 추가 → 저장
5. 휴대폰 B에서 `지금 동기화` 후 같은 날짜 메모 사진 표시 확인
6. B에서 사진 확대보기 확인

8. A에서 사진 삭제 → B 동기화 후 사진 제거 확인
9. 오프라인 상태에서 사진 메모 저장 시 해당 기기에만 저장되는지 확인
10. 온라인 복귀 후 해당 메모를 다시 열고 저장하여 가족 공유 업로드 확인
