# 사진 추가 가이드 (v11.3 preview)

이 버전은 모든 장소에 로컬 사진 슬롯을 미리 만들어 둔 버전입니다.

## 가장 쉬운 사용 방법

1. 넣고 싶은 사진을 JPG 형식으로 준비합니다.
2. 아래 표의 `사진 파일` 경로와 **파일명을 정확히 맞춥니다**.
3. 해당 파일을 ZIP의 `photos/도시폴더/` 안에 넣고 GitHub에 함께 업로드합니다.
4. 새 배포 후 페이지를 새로 열면 일정 카드와 장소 상세에 자동 표시됩니다.

> 로컬 사진이 있으면 로컬 사진을 가장 먼저 사용합니다. 로컬 사진이 없으면 기존에 연결한 Wikimedia 사진 13곳은 자동으로 대체 표시되고, 둘 다 없으면 사진 영역 자체가 숨겨집니다.
