# v12.5 터치 드래그 테스트

1. 일정 탭 → 1/11 다낭 → **편집**
2. 장소 카드 오른쪽 `⠿`를 손가락으로 끌어 1번/2번 순서를 바꾼다.
3. 드롭 후 번호가 1, 2…로 다시 매겨지는지 확인한다.
4. `이동: 렌트차량` 메모의 `⠿`를 끌어 두 장소 사이에 놓는다.
5. 메모를 첫 장소 앞 / 마지막 장소 뒤에도 옮겨 본다.
6. 장소를 메모 위·아래로 교차 이동해 상대 순서가 유지되는지 확인한다.
7. 기존 ↑/↓ 및 일정에서 빼기 / 메모 삭제 버튼도 정상인지 확인한다.
8. 다른 가족 폰에서 동기화 후 같은 순서가 보이는지 확인한다.
9. Today Mode와 지도 방문 순서도 변경된 순서를 반영하는지 확인한다.
